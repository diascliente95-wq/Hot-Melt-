Configurações e proteção dos dados

📲 Instalação no Android

Com o site publicado em HTTPS, abra no Chrome, toque em ⋮ e escolha Instalar app ou Adicionar à tela inicial.

Os dados ficam no armazenamento deste navegador/aparelho. Limpar dados do navegador pode apagá-los.

💾 Backup e restauração

Exporte um arquivo JSON periodicamente e guarde em local seguro.

Restaurar substitui os registros atuais deste aparelho.

⚠️ Limpar dados locais

Apaga todos os registros salvos neste navegador.

☁️ Nuvem e acesso da equipe

Configure o Firebase do seu projeto para sincronizar registros entre aparelhos. A configuração fica salva neste navegador.

Antes de usar com dados reais, habilite Email/Senha no Firebase Authentication, crie o Cloud Firestore e publique as regras de segurança do arquivo firestore.rules do repositório.

Nuvem não configurada.

Uso em equipe

Com Firebase configurado, os registros serão sincronizados entre dispositivos autenticados. As permissões precisam restringir o acesso aos e-mails autorizados da empresa. Faça backup e teste antes de usar como registro oficial.
